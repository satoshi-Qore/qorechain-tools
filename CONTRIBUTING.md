# Contributing

Thank you for considering a contribution to QoreChain Tools.

This repository is a community-maintained collection of operational notes, examples, and helper resources for QoreChain-related infrastructure work.

## Contribution Guidelines

Please keep contributions:

- Practical and easy to verify
- Clear for new node operators
- Free from private keys, wallet seeds, API keys, server passwords, and personal credentials
- Conservative about mainnet, reward, and operator claims
- Aligned with official QoreChain sources for critical or changing network details

## Useful Contributions

Good additions include:

- Safe command examples
- Setup checklists
- Monitoring notes
- Troubleshooting steps
- Placeholder-based configuration examples
- Documentation improvements

## Style

Use short sections, tables, and checklists where possible. Prefer placeholders such as `YOUR_RPC_URL`, `YOUR_CHAIN_ID`, and `YOUR_SERVER_IP` instead of real private values.

## Pull Requests

When opening a pull request, briefly describe:

- What changed
- Why the change is useful
- Whether the change is documentation-only or includes scripts

## Disclaimer

This repository is not official QoreChain documentation. Critical steps should be checked against official sources and current announcements.
